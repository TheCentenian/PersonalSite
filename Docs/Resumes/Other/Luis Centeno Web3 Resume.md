## Selected Projects

### Aqueduct Platform

**Modular Web3 Application Infrastructure**

Designed and prototyped a modular blockchain platform architecture supporting decentralized applications, games, and digital utilities. The platform provides reusable infrastructure for identity management, transaction orchestration, NFT lifecycle management, rewards distribution, and application analytics.

Platform modules include systems for token transaction execution, digital asset creation, balance storage, vault and treasury management, event coordination, and application configuration. The architecture enables applications to integrate blockchain functionality through clearly defined services rather than building individual blockchain logic from scratch.

This project demonstrates system level thinking around decentralized application infrastructure and how blockchain functionality can be integrated into modern application stacks.

---

### Evarra Tracker

Developed a wallet connected application designed to read blockchain transaction data and convert it into human readable financial records and reports.

The system connects to user wallets, performs blockchain queries, and interprets raw transaction data in order to provide structured insights into asset transfers and activity history. The architecture supports both simplified views for new users and deeper analytical views for experienced users.

This project explores improving blockchain transparency and usability by translating complex on chain data into understandable information.

---

### SuiTwo Market Shooter

Developed a blockchain enabled game prototype integrating wallet authentication, NFT assets, score verification, and tournament infrastructure.

The system demonstrates how decentralized assets and blockchain transactions can be integrated into interactive applications. Features include player progression, event coordination, and NFT based digital assets.

The project serves as a proof of concept for how blockchain infrastructure can support real time applications and digital asset ownership.
