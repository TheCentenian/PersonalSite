## Selected Projects

### Evarra Tracker

Designed and built a prototype application that translates complex blockchain transactions into structured, human readable activity.

The system integrates wallet authentication, blockchain query services, and a transaction interpretation layer to provide meaningful summaries of blockchain activity.

The interface supports both simplified views for new users and advanced views for experienced users, allowing users to understand blockchain activity without requiring deep technical knowledge.

Technologies used include React, Next.js, TypeScript, and blockchain query services.

### Aqueduct Platform

Designed a modular infrastructure platform intended to support decentralized applications, games, and digital utilities built on blockchain networks.

The system explores a service oriented architecture that separates application logic from blockchain infrastructure by providing reusable modules for identity, transaction orchestration, digital asset management, rewards distribution, per-player progression (Insignia: opaque key–value bytes per app and wallet), and analytics.

The project demonstrates how decentralized applications can interact with blockchain systems through structured infrastructure services rather than implementing blockchain logic independently.

### SuiTwo Market Shooter

Developed a conceptual prototype exploring how blockchain technology could support interactive digital environments where players own digital assets and participate in competitive events.

The project examines how blockchain assets could represent achievements, progression systems, and rewards while maintaining compatibility with decentralized wallet based ownership.

This project explores the intersection of gaming systems and blockchain infrastructure.
