## Selected Projects

### Aqueduct Platform

**Modular Web3 Application Infrastructure**

Aqueduct is a modular platform architecture designed to support decentralized applications, games, and digital utilities built on the Sui blockchain.

The platform provides reusable services that handle common blockchain related operations such as identity management, token transfers, NFT lifecycle management, rewards distribution, and application configuration.

Rather than requiring each application to directly implement blockchain interactions, Aqueduct allows applications to integrate blockchain capabilities through structured platform modules.

Key architectural components include:

- Identity and access control systems
- Transaction construction and execution services
- Commerce and digital asset management
- Rewards and incentive distribution engines
- Balance and state storage systems
- Wallet-scoped stores for player data the application defines and interprets
- Application configuration and registry services
- Analytics and blockchain query services

The goal of the platform is to simplify the process of building blockchain enabled applications by separating application logic from blockchain infrastructure.

### Evarra Tracker

This project explores improving the usability of blockchain data by translating complex on chain transactions into human readable records and reports.

The system connects to user wallets and retrieves blockchain activity through query services. Raw transaction data is analyzed and converted into structured information that can be organized, categorized, and reviewed.

Features include:

- Wallet connected blockchain access
- Transaction interpretation and categorization
- Human readable financial activity records
- Flexible reporting views for both simple and advanced users

The project demonstrates how blockchain transparency can be improved through better tools for understanding transaction history.

---

### SuiTwo Market Shooter

SuiTwo Market Shooter is a blockchain enabled application prototype designed to explore how decentralized assets and blockchain interactions can be integrated into interactive applications.

The project includes wallet authentication, NFT based digital assets, score verification systems, and tournament style event infrastructure.

Features include:

- Wallet based authentication and identity
- NFT based digital asset ownership
- Score tracking and event coordination
- Player progression and achievement systems

The prototype serves as an experiment in combining blockchain infrastructure with real time applications.
